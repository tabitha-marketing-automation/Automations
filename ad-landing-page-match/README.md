# Ad and Landing Page Match (A/B)

Most ad clicks are lost because the landing page does not match the ad. This folder gives you a free scorecard to check the match, and a test plan to prove which version converts better.

## Who it is for
Small SaaS teams running a few ads (Meta, Google or LinkedIn) that all point to the same generic page.

## The idea
A visitor clicks because of one promise. If the page does not repeat that promise straight away, they leave. This is called message match.

## What is in here
| File | Use |
| --- | --- |
| [message-match-scorecard.md](message-match-scorecard.md) | Score any ad and page pair out of 10 in five minutes |
| [ab-test-plan-template.md](ab-test-plan-template.md) | Fill-in plan for a clean A/B test |
| [worked-example.md](worked-example.md) | An example ad, a generic page (A) and a matched page (B) |

## How to use it
1. Pick one ad. Write down its promise, audience and CTA.
2. Score the page it points to with the scorecard.
3. For anything under 8/10, write a matched version (B).
4. Split traffic 50/50 between A and B and run the test using the plan.
5. Keep the winner. Write the result in the plan so you learn from it.

## Free tools you can use
Google Optimize no longer exists. Free options are Microsoft Clarity for behaviour, Google Analytics 4 for conversions, or simply two pages with different URLs and a 50/50 split in the ad platform, for example separate ads per page.

## Status
The scorecard and plan are templates. The worked example uses an invented product and no real results. Nothing here has been run on a live campaign.
