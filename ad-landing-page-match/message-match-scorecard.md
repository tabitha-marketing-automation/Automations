# Message match scorecard

Score each line 0 (no), 1 (partly) or 2 (yes). Total out of 10.

| # | Check | Score |
| --- | --- | --- |
| 1 | The page headline repeats the ad's main promise in nearly the same words | |
| 2 | The audience named in the ad (for example "small SaaS teams") is named on the page | |
| 3 | The offer is the same: same free trial, guide, price or demo as the ad | |
| 4 | The CTA button says the same thing as the ad CTA, and is visible without scrolling | |
| 5 | The page has one goal, with no menu or links that lead away | |

**8 to 10:** good match, leave it.
**5 to 7:** fix the lowest-scoring lines first.
**0 to 4:** write a new page for this ad.

Notes: tick the line only when you can see it on a phone screen, since most ad clicks come from mobile.
