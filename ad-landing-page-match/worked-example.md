# Worked example (invented product, no real results)

**Product:** "LeadLoop", an imaginary free lead scoring tool for small SaaS teams.

## The ad
- Promise: "Know which leads to call first"
- Audience: small SaaS teams
- Offer: free setup guide
- CTA: Get the free guide

## Page A (generic)
- Headline: "Smarter marketing automation"
- Body: a list of five features
- CTA: "Contact us"
- Scorecard: headline 0, audience 0, offer 0, CTA 0, single goal 1 = **1/10**

## Page B (matched)
- Headline: "Know which leads to call first"
- Subheadline: "A free scoring setup for small SaaS teams"
- Body: three short steps showing how scoring works
- CTA: "Get the free guide", at the top of the page
- Scorecard: 2 + 2 + 2 + 2 + 2 = **10/10**

## The test
Hypothesis: page B will convert more visitors into guide downloads, because it repeats what the ad promised.
One change: the whole message (headline, offer and CTA move together). This is a message test, not a button test.
Primary metric: downloads divided by visitors.
Result: not run. This example only shows how to set up the test.
